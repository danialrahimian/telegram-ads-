چطور کار می‌کند

  1. هر آگهی که اینجا ساخته شود لینکی مثل t.me/{{ settings.bot_username }}?start=c_vaslino_1 دارد.
  2. وقتی کاربر ربات را با این لینک باز کند، تلگرام کد را به‌صورت /start c_vaslino_1 به ربات می‌فرستد.
  3. ربات باید این کد را کنار شناسه‌ی کاربر نگه دارد و وقتی همان کاربر خرید کرد، خرید را با همان کد به این برنامه بفرستد.
  4. آن وقت هزینه‌ی واقعی هر مشتری برای هر آگهی و هر متن حساب می‌شود و قاعده‌ها به‌جای «استارت» با «خرید» تصمیم می‌گیرند.

پیام آماده برای برنامه‌نویس ربات

کلید را جداگانه و امن بفرستید، نه داخل همین پیام.

When a user opens the bot with /start <code>, store <code> with the user id
(keep the first code the user came with). Then send events to:

POST {{ endpoint }}
Authorization: Bearer <CONVERSIONS_SECRET>
Content-Type: application/json

On /start with a code:
{"code": "c_vaslino_1", "event": "start", "id": "start-<telegram_user_id>"}

On every successful purchase by a user who has a stored code:
{"code": "c_vaslino_1", "event": "purchase", "amount": 59000, "id": "order-<order_id>"}

"id" must be unique per event (re-sending the same id is ignored).
"amount" is optional (any currency, used only for totals).
Several events at once: {"events": [ ... ]}  (max 1000)
Reply: {"ok": true, "added": 1, "duplicates": 0, "errors": []}

ورود از فایل CSV

اگر ربات فقط خروجی فروش می‌دهد: ستون‌های code,event,amount,id,ts. فقط code لازم است؛ event پیش‌فرض purchase است؛ ts تاریخ ISO مثل 2026-10-20.
